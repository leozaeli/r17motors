# Fonte Balboa

Adicione aqui o arquivo licenciado da fonte com este nome:

`Balboa-Display.woff2`

O design system já a referencia. Enquanto o arquivo não estiver presente, o navegador usa Georgia como fallback visual.

## Aplicação

- **Balboa:** títulos de campanha, títulos de seção e nomes de veículos. Usar em peso regular, caixa mista e sem tracking adicional.
- **Sans serif:** especificações, valores, CTAs, navegação e informações operacionais. Usar caixa alta apenas nos micro-rótulos.
- **Evitar Balboa:** textos longos, ficha técnica densa, botões e preços — o contraste com a sans mantém a experiência sofisticada e legível.
